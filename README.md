# HotLauncher

macOS 26 retired Launchpad. Apple’s replacement lives in Spotlight, and launching an app often means waiting on that overlay. HotLauncher skips it: up to **20 apps**, one global hotkey each, menu bar only.

- Product page (English): https://hwemo-chung.github.io/hot-launcher.html?lang=en
- Product page (한국어): https://hwemo-chung.github.io/hot-launcher.html
- Source: this repository (`HotLauncher/`)

```bash
cd HotLauncher
bash scripts/bundle.sh
bash scripts/install.sh
```

Not notarized (adhoc). Gatekeeper may block the app on another Mac.
